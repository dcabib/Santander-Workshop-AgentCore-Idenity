# Atribuição dos exemplos e licenças

O workshop adapta exemplos públicos para aulas em português com construção,
inspeção, validação e limpeza dos serviços AWS durante os notebooks.

## AgentCore

Referência principal: [AWS Labs — agentcore-samples](https://github.com/awslabs/agentcore-samples/tree/main/06-workshops),
distribuído sob Apache-2.0. O estudo da conversão SDK usou o commit
`7282ec3b839736d55d199f4c726136c342e33b3c`.

As comparações de Databricks consultaram o
[sample nativo de OBO](https://github.com/awslabs/agentcore-samples/tree/f33b4f14ea46cae2379196948073a6bb4d0e21cf/03-integrations/data-platforms/databricks-dbsql-native-obo).
O projeto não entrega um workspace ou SQL Warehouse real; a referência
multiconta descreve uma fonte sintética na AWS.

## Referência bancária entre contas
