# Estrutura do projeto

| Caminho | Conteúdo |
|---|---|
| `notebooks/` | 18 aulas principais: 13 executáveis e cinco referências |
| `notebooks/20-Extras/` | Quatro exercícios independentes, dados e dependências próprias |
| `scripts/` | Setup, geração, fontes das células, execução e auditoria |
| `src/santander_demo/` | Estado, catálogo e contratos SDK |
| `tests/` | Testes locais de comportamento e material |
| `docs/` | Guias e diagramas externos distribuídos |
| `.workshop/` | Estado por conta/região, gerado e ignorado pelo Git |
| `build/`, `evidence/` | Artefatos de execução, ignorados pelo Git |
| `.venv/` | Ambiente Python, ignorado pelo Git |

O [relatório de 06/11](../RELATORIO_NOTEBOOKS_2026-11-06.md) descreve a auditoria
original e registra posteriormente as correções. Guarde os artefatos locais
de execução para revalidar hashes e respostas.
