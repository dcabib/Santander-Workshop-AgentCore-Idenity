# Contas e elegibilidade

| Coleção | Contas | Situação |
|---|---|---|
| 00–09, 15–16, 99 | Uma conta autorizada | Jornada SDK executável |
| A01–A04 | Uma conta autorizada em us-west-2 | Independentes, kernel próprio |
| 13–14, 90–92 | Arquitetura histórica de quatro contas | Referências sem código; conversão SDK pendente |

Ter quatro contas não torna as referências executáveis. Não há criação,
invocação ou limpeza SDK implementada nesses cinco notebooks.
Databricks representa o contrato de uma fonte sintética; não há workspace,
SQL Warehouse ou Unity Catalog real fornecido.

Disponibilidade regional, modelos, permissões e quotas precisam ser conferidos
na conta participante. A [execução registrada](aceite-notebooks-sdk.md) é
evidência de uma conta e versão específicas.
